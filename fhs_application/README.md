# FHS application

Work from this directory in RStudio, or use the root README's subshell commands. Run `01_prepare_data.R`, `02_analysis.R`, then `03_tables.R`. Install `igraph`, `ape`, `sna` and `numDeriv` beforehand. No data are included or downloaded by these scripts.

## Authorized raw inputs

Put one c1 and one c2 TAB-delimited phenotype table for **each** accession below in `data_raw/` (subfolders are allowed). Plain text and gzip files are supported. Original dbGaP filename versions may differ: filenames must contain the literal accession and a delimited `.c1.`/`.c2.` (or underscore/hyphen equivalent). For example, use the original `pht000031...c1...txt` and `pht000031...c2...txt` filenames, not renamed spreadsheets. The script requires exactly one table per accession/consent group and rejects missing columns. XML dictionaries are not read as tables; consult the authorized release's dictionaries to confirm units and coding. Confirm the study version against your authorized release.

| Accession | Required columns |
|---|---|
| `pht000031` | `shareid`, `B13`, `B14`, `B24`, `B439`, `B443`, `B448` |
| `pht003099` | `shareid`, `age2`, `sex` |
| `pht000836` | `shareid`, `sharealterid`, `ALTERTYPE`, `SPELLBEGIN`, `SPELLEND` |

B13 is weight in kg, B14 is height in cm, B24 is first-physician SBP, and B439/B443/B448 are septal thickness/posterior wall thickness/LV internal dimension in mm. BMI=`weight_kg/height_m^2`; LVM=`1.04*((LVID+septal+posterior)^3-LVID^3)/1000-13.6`; outcome=`LVM/height_m`. Female sex is `sex==2`. Complete cases require BMI, LVM, LVM/height, height, age, sex and SBP; height is used for construction, not an additional regression covariate. Phenotype/demographic shareids must be nonmissing, nonblank and unique after whitespace normalization and c1+c2 binding, with matched consent groups. Invalid sex codes or implausible height, BMI, LVM or SBP stop preparation rather than removing additional participants.

Both endpoints must belong to the common complete cohort. Retain tie spells with `SPELLBEGIN <= 144` and `SPELLEND > 108`. Relatives are `MOTHER`, `FATHER`, `CHILD`, `BROTHER`, `SISTER`; Social ties are `FRIENDNR`, `COWORKERNR`. Treat ties as undirected, remove duplicates/self-ties and exclude isolates separately within each network. Preserve complete-cohort order among retained endpoints. The published counts (3,497 complete cases; Relatives 1,799 nodes/1,687 edges; Social 1,554 nodes/4,812 edges) are comparison targets, not filters or hardcoded analysis inputs.

Preparation saves `data/{relatives,social}/{cohort_private,network_private}.rds` and `data/cohort_flow_private.csv`. Analysis checks cohort/graph alignment, complete values, simple undirected graphs without isolates, full-rank mean design, fit validity and GLS/whitened-regression equivalence. It saves private fits and computed numeric summaries to `results/`. The three tables are generated by `03_tables.R` from those objects; no reference CSV is needed.

Table C1 reports nodes, edges, mean degree, median degree [range], components, largest component n (%), and distance mean (median) and range. Distances are shortest paths over unordered distinct connected pairs only (upper triangle, finite entries, no diagonal). Degree and component summaries use the full network-specific analytic graph. Table C2 has age, female sex, continuous BMI, continuous LVM/height and SBP, with `ape::Moran.I(..., scaled=FALSE, na.rm=FALSE, alternative="greater")`. Table 2 uses ordinary residuals, NAM disturbances and the proposed fit's whitened residuals respectively for the same one-sided test. No real-network plots are generated.

The FHS input reconstruction has not been freshly compared with frozen protected-run IDs/edges/order. Do that comparison in the authorized environment before claiming reproduction of the article's empirical numbers. Repeated runs can overwrite generated files; use a fresh private output directory or preserve earlier results before rerunning.
